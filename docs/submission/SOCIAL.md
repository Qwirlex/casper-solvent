## Launch post

Solvent is live on Casper testnet.

It is an AI agent that runs a DeFi vault and pays its own way. It buys the data and risk
signals it needs from other agents over x402, decides an allocation, and rebalances the
vault on chain. It earns a performance fee as income.

Try it, https://caspersolvent.xyz

## Thread, optional

1/ Most on chain agents are scripts. A human funds every input. For a real agent economy
you need an agent that can earn, can spend, and can prove it paid, with no human in the
loop.

2/ Solvent does the full loop. It runs a vault on Casper. To make each decision it buys a
price feed and a risk score from other agents. Each call is a real x402 handshake, a 402
challenge, an EIP-712 signature, a CEP-18 settlement on chain, then the data.

3/ A bounded decision function picks the allocation, the agent can only choose among a
fixed set and can never move depositor funds to an arbitrary address. The contract
enforces it. Gemini narrates each decision in plain language.

4/ It earns a capped performance fee, the income side. So the agent funds itself. That
is the point, an agent as a real economic actor, on the chain built for it.

5/ Built for the Casper Agentic Buildathon. Live on testnet, open source.
dApp, https://caspersolvent.xyz
code, https://github.com/Qwirlex/casper-solvent
