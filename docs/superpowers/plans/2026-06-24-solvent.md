# Solvent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Solvent, an autonomous fund agent on Casper testnet that runs an on chain DeFi vault and pays other agents over x402 to make each allocation decision.

**Architecture:** Two Odra Rust contracts on casper-test, a CEP-18 pay-token and a vault. Three Node TypeScript services, a data-agent and a risk-agent that sell data behind x402, and a fund-agent driven by Claude that reads chain state, buys feed and risk over x402, then signs and submits a rebalance to the vault. A small dashboard shows the live loop.

**Tech Stack:** Rust with Odra and odra-modules, cargo odra build and test. Node with TypeScript, vitest, Express. The @make-software/casper-x402 package with casper-js-sdk and casper-eip-712. Casper MCP testnet. Claude through the Anthropic API.

- Casper toolchain is new. Phase 0 spikes lock the exact Odra and x402 APIs from a real scaffold and the official demos before any contract or agent code is written. Where a later task shows Odra or x402 code, confirm the exact macro and method names against the scaffold produced in Phase 0 and against the live docs at odra.dev and github.com/make-software/casper-x402. Adjust names if the installed version differs, the shape of the task does not change.
- Testnet only. Gas comes from the free faucet. The only real spend is Claude API.
- Commit after every passing step. Conventional commit messages.
- TDD applies to pure logic, the vault contract and the agent decision and payment logic. Testnet integration is verified by scripted runs, not by unit tests.

```rust
    pub fn total_assets(&self) -> U256 { self.total_assets.get_or_default() }

    pub fn deposit(&mut self, amount: U256) {
        if amount.is_zero() { self.env().revert(Error::ZeroAmount); }
        let caller = self.env().caller();
        let total_shares = self.total_shares.get_or_default();
        let total_assets = self.total_assets.get_or_default();
        let minted = if total_shares.is_zero() || total_assets.is_zero() {
            amount
        } else {
            amount * total_shares / total_assets
        };
        self.shares.set(&caller, self.shares.get_or_default(&caller) + minted);
        self.total_shares.set(total_shares + minted);
        self.total_assets.set(total_assets + amount);
    }

    pub fn withdraw(&mut self, share_amount: U256) {
        let caller = self.env().caller();
        let owned = self.shares.get_or_default(&caller);
        if share_amount.is_zero() { self.env().revert(Error::ZeroAmount); }
        if share_amount > owned { self.env().revert(Error::InsufficientShares); }
        let total_shares = self.total_shares.get_or_default();
        let total_assets = self.total_assets.get_or_default();
        let assets_out = share_amount * total_assets / total_shares;
        self.shares.set(&caller, owned - share_amount);
        self.total_shares.set(total_shares - share_amount);
        self.total_assets.set(total_assets - assets_out);
    }
```

Add tests:
```rust

    pub fn set_fee_bps(&mut self, bps: u16) {
        self.assert_agent();

        self.fee_bps.set(bps);

        let fee = total_assets * U256::from(self.fee_bps.get_or_default()) / U256::from(10000u64);
```

```ts
import type { RiskScore, Decision } from "../shared/types.js";

// Bounded mapping from risk to allocation. The growth weight falls as risk rises.
export function decideAllocation(risk: RiskScore): Decision {
  const growth = Math.max(0, Math.min(100, 100 - risk.score));
  const conservative = 100 - growth;
  const decisionRef = `risk-${risk.score}-growth-${growth}`;
  return {
    allocation: { conservative, growth },
    decisionRef,
    reason: `risk ${risk.score}, ${risk.rationale}`,
  };
}
```

```ts
import { config } from "../shared/config.js";
import { payAndGet } from "./x402Client.js";
import { decideAllocation } from "./decision.js";
import { readVaultState, submitRebalance } from "./chain.js";
import type { Feed, RiskScore } from "../shared/types.js";

export async function runCycle(log: (m: string) => void = console.log): Promise<{ deployHash: string }> {
  const state = await readVaultState();
  log(`vault assets ${state.totalAssets}, allocation ${state.allocation.conservative}/${state.allocation.growth}`);

  const feed = await payAndGet<Feed>(`${config.dataAgentUrl}/feed`);
  log(`bought feed, paid data-agent over x402, price ${feed.price}`);

  const risk = await payAndGet<RiskScore>(`${config.riskAgentUrl}/risk?changePct24h=${feed.changePct24h}`);
  log(`bought risk, paid risk-agent over x402, score ${risk.score}`);

  const decision = decideAllocation(risk);
  log(`decision ${decision.decisionRef}, ${decision.reason}`);

  const deployHash = await submitRebalance(decision.allocation, decision.decisionRef);
  log(`submitted rebalance, deploy ${deployHash}`);
  return { deployHash };
}
```
