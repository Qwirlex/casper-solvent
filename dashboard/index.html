How it works

One decision cycle, six steps, the full economic loop of an agent.

1

Read the market

The agent reads the vault and a price feed through CSPR.cloud on testnet.

2

Pay for data

It buys the feed from the data agent and settles the fee with a real CEP-18 transfer.

3

Pay for risk

It buys a risk score from the risk agent and settles that the same way.

4

Decide

A bounded decision function picks the target allocation and Gemini narrates the reasoning.

5

Rebalance

The agent signs and submits the rebalance to the vault. Only the agent key can move allocation.

6

Earn

The vault skims a capped performance fee, the income side of a self funding agent.

The HTTP 402 wrapper from the casper-x402 package sits on top of the same CEP-18 transfer, turning each priced call into a pay per request exchange with a cryptographic payment proof.
